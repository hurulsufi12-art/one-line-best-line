# One Line, Best Line

A tiny Python program that writes a single line of text to `/output/entry.txt` for the make.fun bounty "One Line, Best Line".

[![Competition](https://make.fun/badge/u-gudril-cool-one-line-best-line-b8c41f4d.svg)](https://make.fun/bounty/u-gudril-cool-one-line-best-line-b8c41f4d)
[![Rank](https://make.fun/badge/u-gudril-cool-one-line-best-line-b8c41f4d/hurulsufi12-art/one-line-best-line/rank.svg)](https://make.fun/bounty/u-gudril-cool-one-line-best-line-b8c41f4d)
[![Reward](https://make.fun/badge/u-gudril-cool-one-line-best-line-b8c41f4d/hurulsufi12-art/one-line-best-line/reward.svg)](https://make.fun/bounty/u-gudril-cool-one-line-best-line-b8c41f4d)

Run with `python3 main.py`. It writes exactly one line (137 characters, ASCII) to `/output/entry.txt`, with no trailing newline.
